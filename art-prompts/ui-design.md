# PawBloom UI Design Prompts

## Art Direction
Japanese mobile game UI, cozy and soft, rounded corners, sticker-like feel, 
playful but not childish, warm colors, paw motifs, gentle shadows

## UI Style Keywords
Soft panels, rounded buttons, illustrated icons, warm shadows, cream backgrounds,
grass green accents, peach coral highlights, gentle gradients, playful typography

## Component Styles

### Buttons
```
Rounded pill button, soft gradient, gentle shadow, Japanese mobile game style,
cozy aesthetic, [COLOR] base with slightly darker bottom, white text,
subtle shine at top, 2px rounded border, game UI asset
```

**Primary Button:** #8CB369 → #6B8F4E
**Secondary Button:** White with #8CB369 border
**Accent Button:** #F4A261 → #E07B3B

### Panels
```
Soft rounded panel, Japanese mobile game UI, warm cream background (#F5E6D3),
subtle shadow, 2px warm border (#E8D5BC), slightly elevated look,
cozy card style, 16-24px corner radius
```

### Icons
```
Simple line icon, 2-3px stroke weight, rounded ends, Japanese cute style,
[ICON_TYPE], warm gray (#3D3D3D), 24x24 or 32x32 grid, game UI asset
```

**Icon Types:**
- Paw print (collection)
- Heart (bond/love)
- Star (rarity)
- Home house
- Walking person
- Gift/treat
- Settings gear
- Arrow back/forward

### Progress Bars
```
Rounded progress bar, soft gradient fill, cream track (#F5E6D3),
[COLOR] fill with subtle shine, Japanese mobile game style,
8-16px height, game UI component
```

### Badges/Tags
```
Small rounded tag, pill shape, [COLOR] background, white text,
Japanese mobile game style, rarity indicator, game UI badge
```

## Motifs & Decorations

### Paw Prints
- Simple 3-pad + main pad design
- Used as background patterns
- Progress indicators
- Button decorations

### Stars/Sparkles
- 4-point or 6-point stars
- Rarity indicators
- Achievement decorations
- Reveal effects

### Hearts
- Rounded heart shape
- Bond level indicators
- Love/affection markers

### Flowers (Sakura)
- 5-petal cherry blossom
- Event decorations
- Special occasion UI

### Leaves
- Simple oval leaf shapes
- Nature/outdoor indicators
- Environmental accents

## Typography Usage

### Display (Nunito Bold)
- Logo text
- Screen titles
- Big numbers

### Body (Nunito Regular)
- Descriptions
- Dialog text
- Instructions

### Accent (Quicksand)
- Taglines
- Special labels
- Decorative text

## Color Application

### Surface Colors
- Main panels: #FFFFFF
- Elevated panels: #FAFAFA
- Background: #FDF8F3
- Disabled: #E8E8E8

### Text Colors
- Primary: #3D3D3D
- Secondary: #6B6B6B
- Muted: #9B9B9B
- On dark: #FFFFFF

### Feedback Colors
- Success: #7CB342
- Warning: #FFB74D
- Error: #E57373
- Info: #89B8D4

## Responsive Considerations
- Touch targets minimum 44×44px
- Comfortable thumb reach zones
- Safe area respect (notch, home indicator)
- Portrait orientation primary
- Desktop: max-width 430px centered
